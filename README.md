# Heart-disease-ml
This project uses classification to determine if a person has heart disease based on features like age, gender and cholesterol.

Input: Age, gender, cp, fbs, restecg, thalach , slope

Model : RandomForestClassifier (RF)

Output: 1 (Healthy) or 0 (Has heart disease)

How it works:
1. Upload the dataset
2. Viewing the dataset
3. Checking the dataset for irrelevant information
4. Defining a function to erase them
5. Understanding the relationship between columns
6. Creating X and y
7. Splitting data into training and testing sets
8. Standardizing the data using Standard Scaler
9. Training model (RandomForest)
10. predicting the output
11. Evaluating the model's accuracy
12. Using confusion matrix to see where the model made mistakes
13. Determining which columns were more important for the model

Results: The model achieved a 82% accuracy on the test data.

1. Dataset cleaning
2. How to use feature importance
